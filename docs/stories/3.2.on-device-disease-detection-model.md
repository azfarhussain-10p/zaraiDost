**Disease Detection Model Requirements**

[Source: prd/epic-3-crop-health-monitoring.md]
- Recognizes 50+ diseases, pests, and nutrient deficiencies
- Covers Pakistani crops: wheat, rice, cotton, sugarcane, corn
- Input: 224x224 RGB images (standard MobileNet input size)
- Output: Class probabilities for 50+ categories + confidence scores
- Target accuracy: >85% on validation dataset
- Target size: <50MB after quantization

**Model Architecture Options**:

1. **MobileNetV2** (Recommended for this use case)
   - Efficient architecture for mobile devices
   - Pre-trained on ImageNet, fine-tuned for crop diseases
   - Good balance of accuracy and speed
   - Size: ~10-15MB after quantization

2. **EfficientNet-Lite**
   - Better accuracy than MobileNet
   - Slightly larger and slower
   - Size: ~20-30MB after quantization

3. **Custom CNN**
   - Optimized specifically for crop diseases
   - Can be smaller but requires more training data
   - Size: ~5-10MB

**TensorFlow Lite Integration** (Extending Story 1.3)

```javascript
import * as tf from '@tensorflow/tfjs';
import '@tensorflow/tfjs-react-native';

// Load disease detection model (extends InferenceEngine from Story 1.3)
class DiseaseDetectionEngine extends InferenceEngine {
  constructor() {
    super();
    this.modelPath = 'models/disease_detection_v1.tflite';
    this.inputSize = 224;
    this.numClasses = 50;
  }

  async loadModel() {
    try {
      // Load TFLite model
      this.model = await tf.loadGraphModel(this.modelPath);
      console.log('Disease detection model loaded');
      return true;
    } catch (error) {
      console.error('Failed to load disease detection model:', error);
      return false;
    }
  }

  async preprocessImage(imageUri) {
    // Resize and normalize image for model input
    const image = await this.loadImageAsTensor(imageUri);

    // Resize to 224x224
    const resized = tf.image.resizeBilinear(image, [this.inputSize, this.inputSize]);

    // Normalize to [0, 1] or [-1, 1] depending on model training
    const normalized = resized.div(255.0);  // [0, 1]
    // OR: const normalized = resized.div(127.5).sub(1);  // [-1, 1]

    // Add batch dimension: [1, 224, 224, 3]
    const batched = normalized.expandDims(0);

    return batched;
  }

  async runInference(imageUri) {
    const startTime = Date.now();

    // Preprocess image
    const inputTensor = await this.preprocessImage(imageUri);

    // Run inference
    const outputTensor = await this.model.predict(inputTensor);

    // Get predictions as array
    const predictions = await outputTensor.data();

    // Clean up tensors
    inputTensor.dispose();
    outputTensor.dispose();

    const inferenceTime = Date.now() - startTime;

    return {
      predictions: Array.from(predictions),
      inferenceTime
    };
  }

  async getTopPredictions(imageUri, topK = 3) {
    const { predictions, inferenceTime } = await this.runInference(imageUri);

    // Get indices and sort by confidence
    const indexedPredictions = predictions.map((prob, index) => ({
      classId: index,
      confidence: prob
    }));

    // Sort by confidence descending
    indexedPredictions.sort((a, b) => b.confidence - a.confidence);

    // Get top K
    const topPredictions = indexedPredictions.slice(0, topK);

    // Map to disease entities with names
    const results = topPredictions.map(pred => ({
      ...this.getDiseaseInfo(pred.classId),
      confidence: pred.confidence,
      confidencePercent: Math.round(pred.confidence * 100)
    }));

    return {
      results,
      inferenceTime,
      modelVersion: this.modelVersion
    };
  }

  getDiseaseInfo(classId) {
    // Lookup disease information from DiseaseDatabase
    return DiseaseDatabase.getByClassId(classId);
  }
}
```

**Result Parsing and Formatting**

```javascript
// Parse model output to user-friendly result
const formatDiseaseResults = async (healthCheckId, imageId, predictions) => {
  const { results, inferenceTime, modelVersion } = predictions;

  // Check confidence threshold
  const highConfidenceResults = results.filter(r => r.confidence >= 0.7);
  const needsCloudVerification = highConfidenceResults.length === 0;

  // Format result object
  const analysisResult = {
    healthCheckId,
    imageId,
    timestamp: new Date().toISOString(),
    modelVersion,
    inferenceTime,
    predictions: results.map((r, index) => ({
      rank: index + 1,
      diseaseId: r.id,
      diseaseName: r.name_en,
      diseaseNameLocal: r.name_ur,  // Based on user language preference
      category: r.category,
      severity: r.severity,
      confidence: r.confidence,
      confidencePercent: r.confidencePercent,
      affectedCrops: JSON.parse(r.affected_crops)
    })),
    topPrediction: results[0],
    needsCloudVerification,
    isOfflineAnalysis: true
  };

  return analysisResult;
};
```

**Multi-Image Analysis Strategy**

When health check has multiple images (up to 5 from Story 3.1):

```javascript
const analyzeHealthCheck = async (healthCheckId) => {
  // Get all images for this health check
  const images = await HealthCheckRepository.getImages(healthCheckId);

  const imageResults = [];
  let totalInferenceTime = 0;

  // Analyze each image sequentially
  for (const image of images) {
    const predictions = await DiseaseDetectionEngine.getTopPredictions(
      image.local_file_path,
      3  // Top 3 predictions
    );

    imageResults.push({
      imageId: image.id,
      predictions: predictions.results,
      inferenceTime: predictions.inferenceTime
    });

    totalInferenceTime += predictions.inferenceTime;
  }

  // Aggregate results across all images
  const aggregatedResult = aggregateMultiImagePredictions(imageResults);

  // Save to database
  await HealthCheckRepository.saveAnalysisResult(healthCheckId, {
    imageResults,
    aggregatedResult,
    totalInferenceTime,
    imageCount: images.length
  });

  return aggregatedResult;
};

// Aggregate predictions from multiple images
const aggregateMultiImagePredictions = (imageResults) => {
  const diseaseVotes = {};

  // Vote counting across images
  imageResults.forEach(imgResult => {
    imgResult.predictions.forEach((pred, index) => {
      const weight = 1.0 / (index + 1);  // Top prediction gets more weight
      const diseaseId = pred.diseaseId;

      if (!diseaseVotes[diseaseId]) {
        diseaseVotes[diseaseId] = {
          ...pred,
          voteScore: 0,
          imageCount: 0
        };
      }

      diseaseVotes[diseaseId].voteScore += pred.confidence * weight;
      diseaseVotes[diseaseId].imageCount += 1;
    });
  });

  // Sort by vote score
  const sortedDiseases = Object.values(diseaseVotes)
    .sort((a, b) => b.voteScore - a.voteScore);

  return {
    topDisease: sortedDiseases[0],
    allCandidates: sortedDiseases.slice(0, 3),
    analysisMethod: 'multi_image_voting'
  };
};
```

### Performance Requirements

[Source: architecture/non-functional-specifications.md]
- **Inference Time**: <5 seconds per image (AC3)
- **Total Analysis**: <15 seconds for 3 images
- **Model Load Time**: <3 seconds on app startup
- **Memory Usage**: <200MB RAM during inference

**Performance Optimization Strategies**:

1. **Model Quantization**: FP32 → INT8 (4x size reduction, minimal accuracy loss)
2. **GPU Acceleration**: Use TFLite GPU delegate on compatible devices
3. **Lazy Loading**: Load model on first use, not app startup
4. **Batch Inference**: Process multiple images in single batch (if supported)
5. **Model Pruning**: Remove unnecessary weights (if accuracy maintained)
6. **Cache Warm-up**: Pre-run inference on dummy image to warm up model
7. **Parallel Processing**: Run inference on background thread
