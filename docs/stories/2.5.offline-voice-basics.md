### Technical Implementation Details

**Offline Speech Recognition Options**

Option 1: **Vosk** (Recommended)
- Open-source offline speech recognition
- Supports multiple languages including Urdu
- Small models (~50MB), can be optimized to <20MB
- Good accuracy for keyword spotting
- React Native compatible via native modules
- Cross-platform (Android & iOS)

Option 2: **TensorFlow Lite Speech Recognition**
- Google's on-device ML framework
- Custom model training possible
- Very small model size (<10MB possible)
- Requires significant setup and training
- Good for keyword spotting

Option 3: **PocketSphinx**
- Lightweight offline speech recognition
- Limited language support (Urdu support unclear)
- Very small model size
- Good for command recognition
- Older technology, less accurate

**Recommended**: Use Vosk for offline speech recognition due to language support, accuracy, and reasonable model size.

```javascript
// OfflineSpeechRecognizer.js
import { Vosk } from 'react-native-vosk';

class OfflineSpeechRecognizer {
  constructor() {
    this.isInitialized = false;
    this.recognizer = null;
    this.modelPath = null;
  }

  async initialize() {
    try {
      // Load offline model from assets
      this.modelPath = await this.extractModelFromAssets();

      // Initialize Vosk recognizer
      const model = await Vosk.createModel(this.modelPath);
      this.recognizer = await Vosk.createRecognizer(model, 16000.0);

      // Set grammar for keyword spotting (optional, improves accuracy)
      const grammar = this.getOfflineCommandGrammar();
      await this.recognizer.setGrammar(grammar);

      this.isInitialized = true;
      console.log('Offline speech recognizer initialized');
    } catch (error) {
      console.error('Offline recognizer initialization failed:', error);
      throw error;
    }
  }

  async recognize(audioUri) {
    if (!this.isInitialized) {
      await this.initialize();
    }

    try {
      // Read audio file
      const audioData = await this.readAudioFile(audioUri);

      // Process audio with Vosk
      const result = await this.recognizer.acceptWaveform(audioData);

      if (result) {
        const finalResult = await this.recognizer.getFinalResult();
        return JSON.parse(finalResult);
      } else {
        const partialResult = await this.recognizer.getPartialResult();
        return JSON.parse(partialResult);
      }
    } catch (error) {
      console.error('Offline recognition failed:', error);
      return { text: '', confidence: 0 };
    }
  }

  getOfflineCommandGrammar() {
    // Define limited grammar for better accuracy
    return [
      'show my crops',
      'show crops',
      'my crops',
      'last advice',
      'previous advice',
      'sync now',
      'synchronize',
      'settings',
      'open settings',
      'show fields',
      'my fields',
      'help',
      'what can I ask',
      // Urdu commands
      'میری فصلیں دکھاؤ',
      'آخری مشورہ',
      'سنک کرو',
      'سیٹنگز',
      'میرے کھیت',
      'مدد',
    ];
  }

  async readAudioFile(uri) {
    // Convert audio file to format Vosk expects
    // This depends on audio library used (expo-av, react-native-fs, etc.)
    const fs = require('react-native-fs');
    const audioBuffer = await fs.readFile(uri, 'base64');
    return audioBuffer;
  }

  async extractModelFromAssets() {
    // Copy model from app bundle to device storage
    const RNFS = require('react-native-fs');
    const modelDir = `${RNFS.DocumentDirectoryPath}/vosk-model-ur`;

    // Check if already extracted
    const exists = await RNFS.exists(modelDir);
    if (exists) {
      return modelDir;
    }

    // Extract from assets
    await RNFS.copyFileAssets('vosk-model-ur', modelDir);
    return modelDir;
  }

  cleanup() {
    if (this.recognizer) {
      this.recognizer.delete();
    }
  }
}

export default new OfflineSpeechRecognizer();
```

**Offline Command Executor**

```javascript
// OfflineCommandExecutor.js
class OfflineCommandExecutor {
  async execute(recognizedText) {
    // Normalize text (lowercase, trim)
    const normalized = recognizedText.toLowerCase().trim();

    // Find matching command
    const command = this.matchCommand(normalized);

    if (!command) {
      return {
        success: false,
        message: 'Command not recognized. Offline voice supports limited commands.',
      };
    }

    // Execute command
    try {
      if (command.screen) {
        // Navigate to screen
        NavigationService.navigate(command.screen);
        return {
          success: true,
          message: `Opening ${command.screen}`,
          action: command.action,
        };
      } else if (command.handler) {
        // Execute handler function
        const result = await command.handler();
        return {
          success: true,
          message: 'Command executed',
          action: command.action,
          data: result,
        };
      }
    } catch (error) {
      console.error('Command execution failed:', error);
      return {
        success: false,
        message: 'Failed to execute command',
        error,
      };
    }
  }

  matchCommand(text) {
    // Search all command categories
    for (const category of Object.values(OFFLINE_COMMANDS)) {
      for (const command of category) {
        for (const keyword of command.keywords) {
          if (text.includes(keyword.toLowerCase())) {
            return command;
          }
        }
      }
    }

    return null;
  }

  getAvailableCommands() {
    // Return list of all offline commands for UI display
    const commands = [];

    for (const [category, commandList] of Object.entries(OFFLINE_COMMANDS)) {
      for (const command of commandList) {
        commands.push({
          category,
          action: command.action,
          examples: command.keywords.slice(0, 2),  // First 2 keywords
        });
      }
    }

    return commands;
  }
}

export default new OfflineCommandExecutor();
```

**Voice Mode Manager**

```javascript
// VoiceModeManager.js
import NetworkMonitor from '@/services/network/NetworkMonitor';
import OfflineSpeechRecognizer from './OfflineSpeechRecognizer';
import SpeechToTextService from './SpeechToTextService';

class VoiceModeManager {
  constructor() {
    this.currentMode = 'online';  // 'online' or 'offline'
    this.preferOffline = false;   // User preference
    this.listeners = [];
  }

  async initialize() {
    // Initialize offline recognizer in background
    OfflineSpeechRecognizer.initialize().catch(err => {
      console.warn('Offline recognizer not available:', err);
    });

    // Subscribe to network changes
    NetworkMonitor.subscribe(this.handleNetworkChange.bind(this));

    // Set initial mode based on network status
    const isOnline = await NetworkMonitor.isConnected();
    this.currentMode = isOnline && !this.preferOffline ? 'online' : 'offline';
  }

  handleNetworkChange(networkStatus) {
    const wasOffline = this.currentMode === 'offline';
    const isOnline = networkStatus.type !== 'none';

    if (this.preferOffline) {
      // User prefers offline mode, don't auto-switch
      return;
    }

    if (wasOffline && isOnline) {
      // Network restored, switch to online
      this.setMode('online');
      this.notifyModeChange('online', 'Network connection restored');
    } else if (!wasOffline && !isOnline) {
      // Network lost, switch to offline
      this.setMode('offline');
      this.notifyModeChange('offline', 'No network connection');
    }
  }

  setMode(mode) {
    if (mode === this.currentMode) return;

    this.currentMode = mode;
    console.log(`Voice mode changed to: ${mode}`);

    // Notify listeners
    this.listeners.forEach(listener => listener(mode));
  }

  async recognize(audioUri) {
    if (this.currentMode === 'online') {
      try {
        return await SpeechToTextService.transcribe(audioUri);
      } catch (error) {
        // Online failed, fallback to offline
        console.warn('Online recognition failed, falling back to offline:', error);
        return await OfflineSpeechRecognizer.recognize(audioUri);
      }
    } else {
      return await OfflineSpeechRecognizer.recognize(audioUri);
    }
  }

  getCurrentMode() {
    return this.currentMode;
  }

  isOfflineMode() {
    return this.currentMode === 'offline';
  }

  setPreferOffline(prefer) {
    this.preferOffline = prefer;
    if (prefer) {
      this.setMode('offline');
    }
  }

  subscribe(listener) {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter(l => l !== listener);
    };
  }

  notifyModeChange(mode, reason) {
    // Show toast or notification
    ToastAndroid.show(`Voice mode: ${mode} (${reason})`, ToastAndroid.SHORT);

    // Optionally announce via TTS
    TextToSpeechService.speak(`Switched to ${mode} voice mode`);
  }
}

export default new VoiceModeManager();
```

### Model Size Optimization

**Strategies to keep model <20MB**:

1. **Use Vosk Small Models**
   - Vosk offers "small" variants (~50MB) vs "large" (~1GB)
   - Small models sufficient for keyword spotting

2. **Model Compression**
   - Quantize model to 8-bit integers (reduces size 4x)
   - Remove unused language features

3. **Grammar-Based Recognition**
   - Use grammar mode (predefined phrases) instead of free-form
   - Much smaller model footprint

4. **Keyword Spotting Only**
   - Train custom TensorFlow Lite model for just 10-20 keywords
   - Can achieve <10MB model size

**Recommended Approach**:
- Start with Vosk small model (~50MB)
- Use grammar mode for limited offline commands
- If size constraint critical, switch to TensorFlow Lite keyword spotting
