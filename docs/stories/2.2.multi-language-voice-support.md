### Technical Implementation Details

**Supported Languages and Codes**

Google Cloud Speech-to-Text language codes:
1. **Urdu (Pakistan)**: `ur-PK`
   - Script: Perso-Arabic (right-to-left)
   - Primary dialect: Pakistani Urdu
   - Native name: اردو

2. **Punjabi (India)**: `pa-IN`
   - Script: Gurmukhi (left-to-right)
   - Alternative script: Shahmukhi (Perso-Arabic, right-to-left) - limited support
   - Native name: ਪੰਜਾਬੀ (Gurmukhi), پنجابی (Shahmukhi)
   - Note: Google primarily supports Gurmukhi script for pa-IN

3. **Sindhi (India)**: `sd-IN`
   - Script: Devanagari (left-to-right)
   - Alternative script: Perso-Arabic (right-to-left)
   - Native name: سنڌي (Perso-Arabic), सिन्धी (Devanagari)
   - Note: Check Google API availability; may need fallback

**Language Manager Service**

```javascript
// LanguageManager.js - Centralized language state management
class LanguageManager {
  constructor() {
    this.currentLanguage = null;
    this.listeners = [];
  }

  async initialize() {
    // Load from AsyncStorage or SQLite
    const savedLanguage = await AsyncStorage.getItem('app_language');
    this.currentLanguage = savedLanguage || 'ur-PK';
    return this.currentLanguage;
  }

  async setLanguage(languageCode) {
    if (!this.isSupported(languageCode)) {
      throw new Error(`Language ${languageCode} not supported`);
    }

    this.currentLanguage = languageCode;
    await AsyncStorage.setItem('app_language', languageCode);
    await this.updateDatabase(languageCode);

    // Notify all listeners
    this.listeners.forEach(listener => listener(languageCode));
  }

  getCurrentLanguage() {
    return this.currentLanguage;
  }

  getLanguageConfig(languageCode) {
    return Object.values(SUPPORTED_LANGUAGES).find(
      lang => lang.code === languageCode
    );
  }

  isSupported(languageCode) {
    return Object.values(SUPPORTED_LANGUAGES).some(
      lang => lang.code === languageCode
    );
  }

  subscribe(listener) {
    this.listeners.push(listener);
    return () => {
      this.listeners = this.listeners.filter(l => l !== listener);
    };
  }
}

export default new LanguageManager();
```

**Multi-Language Speech-to-Text**

Extend SpeechToTextService from Story 2.1:
```javascript
// SpeechToTextService.js
class SpeechToTextService {
  async transcribe(audioUri, languageCode) {
    const config = {
      encoding: 'LINEAR16',
      sampleRateHertz: 16000,
      languageCode: languageCode || 'ur-PK',  // Default to Urdu
      enableAutomaticPunctuation: true,
      model: 'default',
      useEnhanced: true,
    };

    // Add language-specific hints
    if (languageCode === 'pa-IN') {
      config.speechContexts = [{
        phrases: ['ਗੇਹੂੰ', 'ਕਪਾਹ', 'ਚੌਲ'],  // Common crop names in Punjabi
      }];
    } else if (languageCode === 'sd-IN') {
      config.speechContexts = [{
        phrases: ['कपास', 'गेहूं', 'चावल'],  // Common crop names in Sindhi
      }];
    }

    const response = await this.callGoogleAPI(audioUri, config);
    return this.processResponse(response);
  }

  // Language-specific confidence thresholds
  getConfidenceThreshold(languageCode) {
    const thresholds = {
      'ur-PK': 0.9,  // Urdu has better model
      'pa-IN': 0.85, // Punjabi may have slightly lower accuracy
      'sd-IN': 0.80, // Sindhi may need more lenient threshold
    };
    return thresholds[languageCode] || 0.9;
  }
}
```

const LanguageSwitcher = ({ currentLanguage, onChange, compact = false }) => {

          <Text style={styles.langEnglish}>{lang.name}</Text>
        </TouchableOpacity>

**RTL and Script Handling**

Different languages require different text rendering approaches:

```javascript
// RTLSupport.js
import { I18nManager } from 'react-native';

const getTextStyle = (languageCode) => {
  const config = SUPPORTED_LANGUAGES[languageCode];

  return {
    textAlign: config.direction === 'rtl' ? 'right' : 'left',
    writingDirection: config.direction,
    fontFamily: getFontForLanguage(languageCode),
  };
};

const getFontForLanguage = (languageCode) => {
  const fonts = {
    'ur-PK': 'NotoNastaliqUrdu',  // Urdu - Nastaliq script
    'pa-IN': 'NotoSansGurmukhi',  // Punjabi - Gurmukhi script
    'sd-IN': 'NotoSansDevanagari', // Sindhi - Devanagari script
  };
  return fonts[languageCode] || 'System';
};

// Force RTL for Urdu
const configureRTL = (languageCode) => {
  const isRTL = SUPPORTED_LANGUAGES[languageCode]?.direction === 'rtl';
  if (I18nManager.isRTL !== isRTL) {
    I18nManager.forceRTL(isRTL);
    // Note: May require app restart on some platforms
  }
};
```

### Cultural and Linguistic Considerations

**Regional Variations**:
- Urdu: Pakistani dialect (ur-PK) vs Indian dialect (ur-IN)
- Punjabi: Indian Punjabi (pa-IN) uses Gurmukhi; Pakistani Punjabi uses Shahmukhi
- Sindhi: Indian Sindhi uses Devanagari; Pakistani Sindhi uses Perso-Arabic

**Implementation Decision**:
- Focus on Indian language codes (pa-IN, sd-IN) per Google API support
- Consider Pakistani variants in future based on user demand
- Allow manual text input for users whose dialect not well-supported

**Agricultural Terminology**:
- Crop names vary across languages and regions
- Build language-specific vocabulary lists for speech contexts
- Collaborate with agricultural experts for accurate terminology

### Error Handling

Language-specific error scenarios:
1. **Language not supported by API**: Fallback to Urdu with notification
2. **Font loading failure**: Use system font with warning
3. **Low accuracy for language (<80%)**: Suggest Urdu or text input
4. **Language switching during recording**: Gracefully handle mid-session change
5. **i18n translation missing**: Fallback to English or Urdu
