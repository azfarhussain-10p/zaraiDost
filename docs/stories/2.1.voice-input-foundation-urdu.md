### Technical Implementation Details

**Google Speech-to-Text Integration**

Google Speech-to-Text API provides industry-leading accuracy for Urdu language recognition. The API supports streaming and non-streaming recognition modes.

API Configuration:
```javascript
// Speech-to-Text API parameters for Urdu
const speechConfig = {
  encoding: 'LINEAR16',  // Audio encoding format
  sampleRateHertz: 16000,  // Standard rate for mobile
  languageCode: 'ur-PK',   // Urdu (Pakistan)
  enableAutomaticPunctuation: true,
  model: 'default',  // Use enhanced model if available
  useEnhanced: true,
  // Alternative: 'command_and_search', 'phone_call', 'video'
};

// Recognition request
const recognitionRequest = {
  audio: {
    content: base64AudioData  // or uri for streaming
  },
  config: speechConfig
};
```

**Audio Recording Implementation**

Use `expo-av` for audio recording on React Native:
```javascript
import { Audio } from 'expo-av';

// Request permissions
const requestPermissions = async () => {
  const { status } = await Audio.requestPermissionsAsync();
  if (status !== 'granted') {
    // Handle permission denied
  }
};

// Configure recording settings
const recordingOptions = {
  android: {
    extension: '.m4a',
    outputFormat: Audio.RECORDING_OPTION_ANDROID_OUTPUT_FORMAT_MPEG_4,
    audioEncoder: Audio.RECORDING_OPTION_ANDROID_AUDIO_ENCODER_AAC,
    sampleRate: 16000,
    numberOfChannels: 1,
    bitRate: 128000,
  },
  ios: {
    extension: '.m4a',
    outputFormat: Audio.RECORDING_OPTION_IOS_OUTPUT_FORMAT_MPEG4AAC,
    audioQuality: Audio.RECORDING_OPTION_IOS_AUDIO_QUALITY_HIGH,
    sampleRate: 16000,
    numberOfChannels: 1,
    bitRate: 128000,
    linearPCMBitDepth: 16,
    linearPCMIsBigEndian: false,
    linearPCMIsFloat: false,
  },
};

// Start recording
const recording = new Audio.Recording();
await recording.prepareToRecordAsync(recordingOptions);
await recording.startAsync();

// Stop recording (with max duration timeout)
await recording.stopAndUnloadAsync();
const uri = recording.getURI();
```

**Transcription Confidence Handling**

Google Speech-to-Text returns confidence scores (0.0 to 1.0) for each transcription. Implement threshold-based acceptance:

```javascript
// Process transcription results
const processTranscription = (result) => {
  const { transcript, confidence } = result.results[0].alternatives[0];

  if (confidence >= 0.9) {
    // High confidence - auto-accept
    return { text: transcript, requiresReview: false };
  } else if (confidence >= 0.7) {
    // Medium confidence - show for review
    return { text: transcript, requiresReview: true };
  } else {
    // Low confidence - ask user to retry
    return { text: null, requiresReview: true, error: 'LOW_CONFIDENCE' };
  }
};
```

**Urdu Language Considerations**

- Urdu is written right-to-left (RTL)
- Text input fields must support RTL rendering
- Font selection important for proper Urdu display
- Consider diacritic marks (zabar, zer, pesh) in transcription
- Google Speech-to-Text for ur-PK handles Pakistani Urdu dialect

RTL Support in React Native:
```javascript
import { I18nManager } from 'react-native';

// Enable RTL for Urdu
I18nManager.forceRTL(true);

// Text component with RTL support
<Text style={{ textAlign: 'right', writingDirection: 'rtl' }}>
  {urduText}
</Text>
```

**Microphone Permission Flow**

Android (AndroidManifest.xml):
```xml
<uses-permission android:name="android.permission.RECORD_AUDIO" />
```

iOS (Info.plist):
```xml
<key>NSMicrophoneUsageDescription</key>
<string>Zarai Dost needs microphone access to enable voice input for asking questions about your crops.</string>
```

Permission Request Flow:
1. Check if permission already granted
2. If not granted, show rationale dialog (Android) or request dialog (iOS)
3. Request permission
4. Handle granted/denied/never-ask-again states
5. Guide user to settings if permanently denied

**Voice Input Metrics Table**

Track voice input usage and accuracy for analytics:
```sql
CREATE TABLE voice_input_metrics (
  id TEXT PRIMARY KEY,
  query_id TEXT,
  timestamp DATETIME NOT NULL,
  language_code TEXT NOT NULL,              -- 'ur-PK'
  audio_duration_seconds REAL,
  transcription_latency_ms INTEGER,         -- Time to get transcription
  original_transcription TEXT,
  confidence_score REAL,
  user_edited BOOLEAN DEFAULT 0,
  final_text TEXT,
  edit_distance INTEGER,                    -- Number of character changes
  api_request_id TEXT,                      -- Google API request ID
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (query_id) REFERENCES queries(id)
);

CREATE INDEX idx_voice_metrics_timestamp ON voice_input_metrics(timestamp DESC);
CREATE INDEX idx_voice_metrics_language ON voice_input_metrics(language_code);
```

### Error Handling

Common error scenarios:
1. **No microphone permission**: Show permission dialog with rationale
2. **Recording too short (<1s)**: "Please speak for at least 1 second"
3. **Recording too long (30s timeout)**: Auto-stop and process
4. **No network connection**: "Voice input requires internet. Please type your question or try again when online."
5. **API quota exceeded**: "Voice service temporarily unavailable. Please type your question."
6. **Low confidence (<0.7)**: "We couldn't understand clearly. Please try again or type your question."
7. **API error (500)**: "Something went wrong. Please try again."
