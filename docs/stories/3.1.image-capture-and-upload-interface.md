# Story 3.1: Image Capture and Upload Interface

## Status
Draft

## Story
**As a** farmer observing potential crop problems,
**I want** to take a photo of my crop through the app,
**so that** the AI can analyze what's wrong.

## Acceptance Criteria
1. AC1: Camera interface accessible from main dashboard
2. AC2: Photo capture with crop type selection (dropdown or voice)
3. AC3: Image preview with retake/confirm options

5. AC5: Image quality validation (minimum resolution, not blurry)
6. AC6: Multiple images uploadable for same crop issue (max 5)
7. AC7: Location data (GPS) captured with image for regional analysis

### Technical Implementation Details

**Camera Libraries - React Native Options**

Option 1: `react-native-camera` (Community)
- Comprehensive camera controls
- Supports barcode scanning, face detection
- Good for advanced features
- Larger bundle size

Option 2: `expo-camera` (Expo framework)
- Simpler API, easier setup
- Part of Expo managed workflow
- Good for standard camera needs
- Recommended for this implementation

Option 3: `react-native-image-picker` (Basic)
- Simpler, just image picking
- No custom camera UI
- Limited customization

**Recommended**: Use `expo-camera` for camera capture + `expo-image-picker` for gallery selection.

**Image Quality Validation**

**Blur Detection Algorithm** (Laplacian Variance):
```javascript
// Blur detection using Laplacian variance
// Lower variance = more blur
const detectBlur = async (imageUri) => {
  // Use image-processing library like react-native-image-filter-kit
  // or custom native module for cv2.Laplacian equivalent

  // Simplified logic:
  const laplacianVariance = await calculateLaplacian(imageUri);

  const BLUR_THRESHOLD = 100;  // Threshold value (tune based on testing)

  if (laplacianVariance < BLUR_THRESHOLD) {
    return { isBlurry: true, score: laplacianVariance };
  }
  return { isBlurry: false, score: laplacianVariance };
};
```

**Resolution Validation**:

const validateResolution = (width, height) => {

**File Size Validation**:
```javascript
const validateFileSize = async (uri) => {
  const fileInfo = await FileSystem.getInfoAsync(uri);
  const MAX_SIZE_MB = 10;
  const sizeInMB = fileInfo.size / (1024 * 1024);

  if (sizeInMB > MAX_SIZE_MB) {
    return {
      valid: false,
      message: `Image too large (${sizeInMB.toFixed(1)}MB). Max ${MAX_SIZE_MB}MB.`
    };
  }
  return { valid: true };
};
```

**GPS Location Capture**

```javascript
import * as Location from 'expo-location';

const captureLocation = async () => {
  // Request permissions
  const { status } = await Location.requestForegroundPermissionsAsync();
  if (status !== 'granted') {
    return null;  // Handle gracefully
  }

  // Get current location
  const location = await Location.getCurrentPositionAsync({
    accuracy: Location.Accuracy.Balanced,  // Balance accuracy and battery
  });

  return {
    latitude: location.coords.latitude,
    longitude: location.coords.longitude,
    accuracy: location.coords.accuracy,
    timestamp: location.timestamp,
  };
};

// Extract GPS from EXIF data (alternative if image already has GPS)
const extractGPSFromExif = (exifData) => {
  if (!exifData || !exifData.GPSLatitude) {
    return null;
  }

  return {
    latitude: convertGPSToDecimal(exifData.GPSLatitude, exifData.GPSLatitudeRef),
    longitude: convertGPSToDecimal(exifData.GPSLongitude, exifData.GPSLongitudeRef),
  };
};
```

### Data Model Requirements

**New Table: health_checks**

Track crop health check sessions (grouping multiple images):
```sql
CREATE TABLE health_checks (
  id TEXT PRIMARY KEY,                      -- UUID
  farmer_id TEXT NOT NULL,
  field_id TEXT,                            -- Optional field association
  crop_id TEXT,                             -- Optional crop association
  crop_type TEXT NOT NULL,                  -- wheat, rice, cotton, etc.
  description TEXT,                         -- Optional farmer description
  location_latitude REAL,
  location_longitude REAL,
  location_accuracy REAL,
  image_count INTEGER DEFAULT 0,            -- Number of images in this check
  status TEXT DEFAULT 'pending',            -- pending, analyzing, completed
  on_device_result TEXT,                    -- JSON from Story 3.2
  cloud_result TEXT,                        -- JSON from Story 3.3
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  sync_status TEXT DEFAULT 'pending',
  FOREIGN KEY (farmer_id) REFERENCES farmers(id),
  FOREIGN KEY (field_id) REFERENCES fields(id),
  FOREIGN KEY (crop_id) REFERENCES crops(id)
);

CREATE INDEX idx_health_checks_farmer ON health_checks(farmer_id);
CREATE INDEX idx_health_checks_created ON health_checks(created_at DESC);
CREATE INDEX idx_health_checks_status ON health_checks(status);
```

**Update images table** (extend from Story 1.1):

### Performance Requirements

- **Validation**: Quality checks complete within 1 second
- **Gallery Load**: Display gallery picker within 1 second

- Use thumbnail generation for preview carousel
- Lazy load quality validation (run after preview shown)
- Cache GPS location between captures (reuse if <1 minute old)
