# Story 2.4: Contextual Voice Commands

## Status
Approve

## Story
**As a** farmer using voice regularly,
**I want** to use natural commands like "check my wheat crop" or "when should I water",
**so that** I can navigate the app without touching the screen.

## Acceptance Criteria
1. AC1: Voice commands parsed for intent (crop health check, irrigation, market prices)
2. AC2: Natural language understanding handles variations in phrasing
3. AC3: Contextual follow-up questions supported ("what about my corn field?")
4. AC4: Command confirmation for destructive actions
5. AC5: Help command ("what can I ask?") provides voice-guided examples
6. AC6: Command history accessible via voice ("repeat last query")

**Intent Categories and Examples**

Core intents for agricultural app:

1. **Crop Health Check** (`crop_health`)
   - Urdu: "میری گندم کی فصل کی صحت چیک کریں", "کپاس کیسی ہے"
   - English variations: "check my wheat crop", "how is my cotton doing", "wheat health"

2. **Irrigation/Watering** (`irrigation`)
   - Urdu: "کب پانی دینا ہے", "آج پانی دوں"

3. **Market Prices** (`market_prices`)
   - Urdu: "گندم کی قیمت کیا ہے", "مارکیٹ بھاؤ"

4. **Weather** (`weather`)
   - Urdu: "موسم کیسا ہے", "بارش ہوگی"
   - English: "weather", "will it rain", "forecast"

5. **Planting/Harvesting** (`crop_lifecycle`)
   - Urdu: "کب بونا ہے", "کٹائی کا وقت"
   - English: "when to plant", "harvest time", "sowing date"

6. **Pest/Disease** (`pest_disease`)
   - Urdu: "کیڑا لگا ہے", "بیماری کا علاج"
   - English: "pest problem", "disease treatment", "crop infection"

7. **Navigation** (`navigation`)
   - Urdu: "میرے کھیت دکھاؤ", "سیٹنگز"

   - Urdu: "مدد", "میں کیا پوچھ سکتا ہوں"
   - English: "help", "what can I ask", "show commands"

   - Urdu: "پچھلا سوال دوبارہ", "تاریخ"
   - English: "repeat last query", "show history", "previous question"

**Intent Classification with LangChain**

```javascript
// IntentClassifier.js
import { PromptTemplate, LLMChain } from 'langchain/prompts';
import { ChatOpenAI } from 'langchain/chat_models/openai';
import AIWrapper from '@/services/ai/AIWrapper';

class IntentClassifier {
  constructor() {
    this.llm = AIWrapper.getModel();
    this.intentPrompt = this.createIntentPrompt();
  }

  createIntentPrompt() {
    const template = `You are a voice command classifier for an agricultural app.
Classify the user's voice command into one of these intents:
- crop_health: Checking crop health or condition
- irrigation: Questions about watering/irrigation
- market_prices: Market rates and prices
- weather: Weather forecasts
- crop_lifecycle: Planting, harvesting schedules
- pest_disease: Pest or disease problems
- navigation: App navigation commands
- help: User needs help
- history: Repeat or view previous queries
- general: General agricultural questions

Extract entities like:
- crop_type: wheat, cotton, rice, corn, etc.
- field_name: Field A, North Field, etc.
- date: today, tomorrow, next week, etc.

User language: {language}
User command: {command}

Return JSON:
{{
  "intent": "<intent_name>",
  "confidence": <0-1>,
  "entities": {{
    "crop_type": "<crop>",
    "field_name": "<field>",
    "date": "<date>"
  }},
  "parameters": {{}}
}}`;

    return new PromptTemplate({
      template,
      inputVariables: ['language', 'command'],
    });
  }

  async classify(command, language = 'ur-PK') {
    try {
      const chain = new LLMChain({
        llm: this.llm,
        prompt: this.intentPrompt,
      });

      const result = await chain.call({
        language,
        command,
      });

      const parsed = JSON.parse(result.text);

      // Validate confidence threshold
      if (parsed.confidence < 0.6) {
        return {
          intent: 'general',
          confidence: parsed.confidence,
          entities: {},
          fallback: true,
        };
      }

      return parsed;
    } catch (error) {
      console.error('Intent classification failed:', error);
      return {
        intent: 'general',
        confidence: 0,
        entities: {},
        error: true,
      };
    }
  }

  // Fallback to rule-based classification for offline mode
  classifyOffline(command, language) {
    const rules = this.getRulesForLanguage(language);

    for (const [intent, patterns] of Object.entries(rules)) {
      for (const pattern of patterns) {
        if (pattern.test(command)) {
          return {
            intent,
            confidence: 0.8,
            entities: this.extractEntitiesOffline(command),
            offline: true,
          };
        }
      }
    }

    return {
      intent: 'general',
      confidence: 0.5,
      entities: {},
      offline: true,
    };
  }

  getRulesForLanguage(language) {
    const urduRules = {
      crop_health: [/صحت|حالت|کیسی/i, /health|condition/i],
      irrigation: [/پانی|سیراب/i, /water|irrigat/i],
      market_prices: [/قیمت|بھاؤ|مارکیٹ/i, /price|rate|market/i],
      weather: [/موسم|بارش/i, /weather|rain|forecast/i],
      help: [/مدد|ہیلپ/i, /help|what can/i],
      history: [/دوبارہ|پچھلا/i, /repeat|previous|last/i],
    };

    return urduRules;  // Extend for other languages
  }

  extractEntitiesOffline(command) {
    const entities = {};

    // Extract common crop names
    const cropPatterns = {
      wheat: /گندم|wheat/i,
      cotton: /کپاس|cotton/i,
      rice: /چاول|rice/i,
      corn: /مکئی|corn/i,
    };

    for (const [crop, pattern] of Object.entries(cropPatterns)) {
      if (pattern.test(command)) {
        entities.crop_type = crop;
        break;
      }
    }

    return entities;
  }
}

export default new IntentClassifier();
```

**Conversation Context Management**

```javascript
// ConversationContext.js
class ConversationContext {
  constructor() {
    this.context = {
      currentCrop: null,
      currentField: null,
      lastIntent: null,
      lastEntities: {},
      history: [],
      timestamp: null,
    };
    this.expirationMinutes = 5;
  }

  update(intent, entities) {
    this.context.lastIntent = intent;
    this.context.lastEntities = entities;
    this.context.timestamp = Date.now();

    // Update current context
    if (entities.crop_type) {
      this.context.currentCrop = entities.crop_type;
    }
    if (entities.field_name) {
      this.context.currentField = entities.field_name;
    }

    // Add to history
    this.context.history.push({
      intent,
      entities,
      timestamp: Date.now(),
    });

    // Limit history to last 10 items
    if (this.context.history.length > 10) {
      this.context.history.shift();
    }
  }

  resolveReferences(command, entities) {
    // Resolve pronouns and implicit references
    const resolved = { ...entities };

    // "it", "that crop", "اس فصل"
    if (this.containsReference(command)) {
      if (!resolved.crop_type && this.context.currentCrop) {
        resolved.crop_type = this.context.currentCrop;
      }
      if (!resolved.field_name && this.context.currentField) {
        resolved.field_name = this.context.currentField;
      }
    }

    return resolved;
  }

  containsReference(command) {
    const referencePatterns = [
      /\bit\b/i,
      /that/i,
      /اس/,
      /وہ/,
    ];

    return referencePatterns.some(pattern => pattern.test(command));
  }

  isExpired() {
    if (!this.context.timestamp) return true;

    const now = Date.now();
    const elapsed = now - this.context.timestamp;
    const expirationMs = this.expirationMinutes * 60 * 1000;

    return elapsed > expirationMs;
  }

  reset() {
    this.context = {
      currentCrop: null,
      currentField: null,
      lastIntent: null,
      lastEntities: {},
      history: [],
      timestamp: null,
    };
  }

  getLastCommand() {
    if (this.context.history.length === 0) return null;
    return this.context.history[this.context.history.length - 1];
  }

  getCommandHistory(count = 5) {
    return this.context.history.slice(-count).reverse();
  }
}

export default new ConversationContext();
```

**Command Execution Engine**

```javascript
// CommandExecutor.js
class CommandExecutor {
  async execute(intent, entities, context) {
    const handlers = {
      crop_health: this.handleCropHealth,
      irrigation: this.handleIrrigation,
      market_prices: this.handleMarketPrices,
      weather: this.handleWeather,
      crop_lifecycle: this.handleCropLifecycle,
      pest_disease: this.handlePestDisease,
      navigation: this.handleNavigation,
      help: this.handleHelp,
      history: this.handleHistory,
      general: this.handleGeneral,
    };

    const handler = handlers[intent] || this.handleGeneral;
    return await handler.call(this, entities, context);
  }

  async handleCropHealth(entities, context) {
    const crop = entities.crop_type || context.currentCrop;

    if (!crop) {
      return {
        type: 'clarification',
        message: 'Which crop would you like to check?',
        options: ['wheat', 'cotton', 'rice', 'corn'],
      };
    }

    // Query crop health from database
    const cropData = await CropRepository.findByCropType(crop);

    // Call AI for health analysis
    const analysis = await AIWrapper.analyzeCropHealth(cropData);

    return {
      type: 'response',
      message: analysis,
      data: cropData,
    };
  }

  async handleIrrigation(entities, context) {
    const crop = entities.crop_type || context.currentCrop;
    const field = entities.field_name || context.currentField;

    // Get irrigation schedule
    const schedule = await IrrigationService.getSchedule(crop, field);

    return {
      type: 'response',
      message: `Next watering for ${crop}: ${schedule.nextWatering}`,
      data: schedule,
    };
  }

  async handleMarketPrices(entities, context) {
    const crop = entities.crop_type || context.currentCrop;

    const prices = await MarketService.getPrices(crop);

    return {
      type: 'response',
      message: `Current ${crop} price: ${prices.current}`,
      data: prices,
    };
  }

  async handleHelp(entities, context) {
    const examples = [
      'Check my wheat crop health',
      'When should I water my cotton field?',
      'What is the current wheat price?',
      'Will it rain tomorrow?',
      'Show my fields',
    ];

    return {
      type: 'help',
      message: 'You can ask things like:',
      examples,
    };
  }

  async handleHistory(entities, context) {
    const history = ConversationContext.getCommandHistory(5);

    return {
      type: 'history',
      message: 'Your recent questions:',
      data: history,
    };
  }

  async handleNavigation(entities, context) {
    // Navigate to app screen
    const screen = this.detectScreenName(entities);

    return {
      type: 'navigation',
      screen,
      message: `Navigating to ${screen}`,
    };
  }

  async handleGeneral(entities, context) {
    // Fallback to general AI query
    const response = await AIWrapper.query(context.originalCommand);

    return {
      type: 'response',
      message: response,
    };
  }

  detectScreenName(entities) {
    // Map entities to screen names
    const screenMap = {
      fields: 'FieldsScreen',
      crops: 'CropsScreen',
      settings: 'SettingsScreen',
      market: 'MarketScreen',
      weather: 'WeatherScreen',
    };

    // Simple keyword matching
    for (const [keyword, screen] of Object.entries(screenMap)) {
      if (entities.screen_keyword === keyword) {
        return screen;
      }
    }

    return 'HomeScreen';
  }
}

export default new CommandExecutor();
```

      await TextToSpeechService.speak(example, { language });
      await new Promise(resolve => setTimeout(resolve, 500));  // Pause between
    }
  }
}

### Error Handling

Command error scenarios:
1. **Unclear intent (<60% confidence)**: Ask for clarification or fallback to general query
2. **Missing entities**: Ask user to specify (e.g., "Which crop?")
3. **Command execution failed**: Inform user, offer retry
4. **Confirmation timeout**: Cancel action, return to main screen
5. **Context expired**: Ask user to repeat full command
6. **Offline with complex command**: Suggest simpler command or text input

### Future Enhancements (Out of Scope for 2.4)

- Proactive suggestions ("You haven't checked wheat in 3 days, want to?")
- Voice shortcuts/macros (custom commands)
- Third-party integration commands ("Order fertilizer from XYZ")
- Voice authentication for sensitive commands
